**Wangila W. Job — IT Support & Cybersecurity Operations | Networking | Full-Stack Development | Remote-Ready.**

A single-page portfolio and CV site built with semantic HTML5, custom CSS3, and vanilla JavaScript. Dark/light theme, cursor-glow effects, scroll animations, and Plausible analytics.

## Live

- **Portfolio:** https://jobw.dev
- **CV (online):** https://jobw.dev/cv
- **Deployment:** Vercel (jobw-dev.vercel.app)

## Features

- Responsive single-page layout with sections: Services, About, Portfolio, Skills, Availability, Testimonials, Contact
- Dark / light theme toggle with system-preference detection
- Animated stat counters, typing effect, smooth scrolling, back-to-top
- SEO meta, Open Graph + Twitter cards, sitemap, robots.txt, custom 404 page
- Contact form wired to Formspree
- Print-friendly online CV page (`cv.html`)

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript (no frameworks)
- Fonts: Space Grotesk, Inter (Google Fonts)
- Analytics: Plausible.io
- Hosting: Vercel (`vercel.json` — clean URLs + security headers)

## Local Development

```bash
# serve the static site locally
python3 -m http.server 8080
# open http://localhost:8080
```

No build step required.
